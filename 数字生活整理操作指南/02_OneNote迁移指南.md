# 📝 OneNote迁移指南 (渐进式)

> 不要一次性迁移,每天1-2页,4周完成

---

## 🎯 目标

- **不是**: 把所有OneNote内容搬到Notion
- **而是**: 只把"未来有价值"的内容迁移过去

---

## ⚠️ 迁移前的心理准备

### 你不需要迁移所有内容

问问自己:
- 这条笔记我最后一次看是什么时候?
- 未来1年我会用到它吗?
- 如果这条笔记消失了,会影响我的生活吗?

**大部分答案是"不会"** → 那就不用迁移

### 迁移比例建议
- 迁移: 20-30%的内容
- 删除: 50-60%的内容
- 暂时保留: 10-20%的内容(以后再决定)

---

## 📋 第一步：评估OneNote现状

### 打开OneNote,回答这些问题

1. **有多少个笔记本?**
   - 写下来: ____个

2. **每个笔记本有多少分区?**
   - 估算总分区数: ____个

3. **总共有多少页笔记?**
   - 粗略估计: ____页

4. **哪些笔记本最重要?**
   - 列出Top 3:
     - ____
     - ____
     - ____

### 预估迁移时间
| 笔记总数 | 预计天数 | 每日迁移量 |
|----------|----------|------------|
| 100页 | 7天 | 15页/天 |
| 500页 | 20天 | 25页/天 |
| 1000页 | 30天 | 35页/天 |

---

## 🗂️ 第二步：笔记分类与去留判断

### 打开每个笔记,问3个问题

**Q1: 这是什么类型的笔记?**

| 类型 | 去向 |
|------|------|
| 学习笔记 | → Notion知识库或学习项目 |
| 灵感想法 | → Notion灵感收集箱 |
| 待办事项 | → Notion任务库 |
| 参考资料 | → Notion资料库 |
| 日记/反思 | → Notion日记 |
| 纯收藏(没加工) | → 考虑删除 |

**Q2: 内容有没有过期?**

| 情况 | 处理 |
|------|------|
| 考研/面试笔记,但已经考完 | 删除或存档 |
| 某个项目的笔记,项目已结束 | 删除或存档 |
| 某个课程笔记,课程已修完 | 判断是否有复习价值 |
| 某个软件教程,但软件已更新 | 删除 |

**Q3: 未来我会用到它吗?**
- 会 → 迁移
- 不会 → 删除
- 不确定 → 标记,以后再说

---

## 🔄 第三步：迁移操作流程

### 单页迁移流程 (3分钟/页)

```
打开OneNote页面 → 判断价值 → 复制内容 → 粘贴到Notion → 整理格式 → 删除/标记原页
```

### 具体操作步骤

#### 1. 复制OneNote内容
- Ctrl+A 全选
- Ctrl+C 复制

#### 2. 粘贴到Notion
- 在Notion新建页面
- Ctrl+V 粘贴
- Notion会自动保留基本格式

#### 3. 整理格式
- 检查标题层级
- 检查图片是否正常显示
- 删除多余空行

#### 4. 添加到数据库
根据笔记类型,添加到对应数据库:
- 知识类 → 知识库
- 想法类 → 灵感收集箱
- 任务类 → 任务库

#### 5. 处理原页
- 已迁移 → 在OneNote中标记或删除
- 可以在页面标题前加 `[已迁移]`

## 📊 不同类型笔记的迁移方案

### 1. 学习笔记 (如CS课程笔记)

**判断标准**:
- 这个知识点我掌握了吗?
- 未来我会复习这个内容吗?

**迁移方式**:
- 创建学习项目 (如"CS50课程")
- 把笔记作为项目的子页面
- 或者整理成知识库条目

**示例**:
```
OneNote: "数据结构-链表笔记"
→ Notion: 学习项目"数据结构"/子页面"链表"
```

### 2. 碎片想法 (灵感、随手记)

**判断标准**:
- 这个想法现在还有价值吗?
- 我会基于这个想法行动吗?

**迁移方式**:
- 直接复制到灵感收集箱
- 不用整理格式
- 批量迁移即可

**示例**:
```
OneNote: "想做一个记账App"
→ Notion: 灵感收集箱/想法
```

### 3. 待办事项

**判断标准**:
- 这个任务还需要做吗?
- 截止日期过了吗?

**迁移方式**:
- 还需要做 → 任务库
- 已过期 → 直接删除

### 4. 资料收集 (链接、截图)

**判断标准**:
- 这些资料我整理过吗?
- 未来我会用到吗?

**迁移方式**:
- 有价值 → 知识库(每个链接一条)
- 只是收藏没看过 → 考虑删除

### 5. 日记/周记

**判断标准**:
- 我会回顾这些日记吗?
- 有没有情感价值?

**迁移方式**:
- 有价值 → Notion日记数据库
- 太旧了 → 可以不迁移

## 💡 批量迁移技巧

### 1. 使用AI总结长笔记

如果一页笔记很长很乱:
1. 全选复制
2. 粘贴给ChatGPT/Claude
3. 让AI帮你:
   - 总结核心内容
   - 提取要点
   - 整理成结构化格式
4. 把AI整理后的内容粘贴到Notion

### 2. 同类笔记批量处理

例如有10页"Python学习笔记":
1. 在Notion创建"Python学习"子页面
2. 把10页内容合并到这个页面
3. 整理成目录结构

### 3. 截图类笔记处理

如果笔记里都是截图:
- 判断截图是否还有价值
- 有价值 → 直接粘贴到Notion(Notion支持图片)
- 没价值 → 删除

## ⚠️ 常见问题

### Q: 笔记太多,不知道从哪开始?
A: 从"最近使用"或"最重要"的笔记本开始,不要从最旧的开始

### Q: 格式乱了怎么办?
A: 简单整理即可,不用追求完美格式。内容比格式重要

### Q: 图片粘贴不过去?
A:
1. 先保存图片到本地
2. 在Notion中拖拽上传
3. 或者使用截图直接粘贴

### Q: 我舍不得删怎么办?
A:
1. 先迁移到Notion
2. OneNote保留1个月
3. 1个月后确认没问题再删除

### Q: 有些笔记很乱,看不懂了?
A: 看不懂 = 没价值 → 直接删除
