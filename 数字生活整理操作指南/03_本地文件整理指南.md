## 📂 第一部分：文件夹结构设计

### 你的错误做法
```
❌ 把一张图复制到多个文件夹:
📁 风景/蓝色天空.jpg
📁 蓝色/蓝色天空.jpg
📁 壁纸/蓝色天空.jpg
→ 3份文件,3倍空间!
```

### 正确做法
```
✅ 文件只放一个位置,用Notion打标签:
📁 Media/照片/风景/蓝色天空.jpg (只有1份)
→ Notion资料库: 标签=[风景, 蓝色, 壁纸]
```

## 🏗️ 顶层文件夹结构 (永远不变)

```
📁 1-生活 Life
📁 2-学习 Study
📁 3-工作 Work
📁 4-媒体 Media
📁 5-存档 Archive
```

### 为什么这样分?
- 数字前缀 → 保持排序不变
- 大类不超过5个 → 容易记忆
- 涵盖所有场景 → 不会找不到地方放

## 📝 文件命名规范

### 统一格式
```
日期_主题_内容
```

### 示例
```
2025-01_CS基础_数据结构笔记.md
2025-02_求职_腾讯面试准备.docx
2024-12_旅行_北京故宫照片.zip
```

### 为什么这样命名?
- 日期在前 → 自动按时间排序
- 主题明确 → 一眼看出是什么
- 不用复杂分类 → 搜索时更容易找到

## 🖼️ 照片整理：三步法

### Step 1: 删除无用照片 (最重要!)

**批量删除这些:**
- ❌ 模糊的照片
- ❌ 重复的照片(连拍)
- ❌ 纯黑/纯白的失败照片
- ❌ 已经没用的截图
- ❌ 临时拍的备忘(已处理)
- ❌ 3年前的且不会再看的

**预计可删除: 30-50%**

### Step 2: 简单分类

你只需要这4个文件夹:
```
📁 4-媒体/A-照片
   ├── 📁 人物 (自拍、合照、家人)
   ├── 📁 风景 (旅行、日常风景)
   ├── 📁 截图 (手机截图、电脑截图)
   └── 📁 其他 (美食、宠物、杂项)
```

**不要分太细!** 4个分类足够90%场景。

### Step 3: 按年份归档

```
📁 A-照片
   ├── 📁 2023
   │   ├── 人物
   │   ├── 风景
   │   ├── 截图
   │   └── 其他
   ├── 📁 2024
   └── 📁 2025
```

## 🤖 本地AI自动分类方案

### 方案1: DigiKam (免费开源)

**特点:**
- 完全本地,不上传
- 自动人脸识别
- 自动标签(猫、狗、食物、建筑等)
- 支持几万张照片

**安装:**
1. 下载: https://www.digikam.org/download/
2. 安装后打开
3. 添加你的照片文件夹
4. 等待扫描完成(首次较慢)

**使用方法:**
1. 菜单 → 工具 → 维护
2. 勾选"人脸检测"、"图像质量排序"
3. 运行
4. 软件会自动:
   - 识别人脸并分组
   - 检测模糊照片
   - 标记相似/重复照片

### 方案2: Windows相册

**特点:**
- 已经装好了
- 自动按人物、地点分类
- 简单易用

**使用方法:**
1. 打开Windows相册应用
2. 设置 → 添加你的照片文件夹
3. 等待索引完成
4. 点击"人物"标签 → 自动分组
5. 点击"地点"标签 → 按地理位置分

### 方案3: 手机相册APP

**iPhone/Android相册都有:**
- 人物相册(自动人脸分组)
- 地点相册
- 智能分类(截图、美食、宠物等)

## 🎨 素材类文件整理 (画师图、壁纸)

### 问题
你收藏了很多二次元画师图,想要多个标签

### 解决方案

**文件只存一份:**
```
📁 4-媒体/D-素材/画师图/画师名/作品.jpg
```

**在Notion资料库打标签:**
```
资源名称: xxx画师作品集
类型: 灵感
分类: 设计
标签: [二次元, 人物, 蓝色, 收藏]
路径: D:/Media/素材/画师图/xxx/
```

这样:
- 本地只有1份文件
- Notion有多个标签
- 搜索"蓝色"就能找到

## 🔧 解决重复文件问题

### 方案1: 使用Duplicate Cleaner (免费)

**作用**: 找出重复文件,批量删除

**使用步骤:**
1. 下载: https://www.duplicatecleaner.com/
2. 选择要扫描的文件夹
3. 点击"开始扫描"
4. 查看重复文件列表
5. 选择要删除的(保留1份)
6. 删除

### 方案2: Windows自带
```
搜索栏输入: *.jpg size:>1MB
找出大图片,手动检查重复
```

## 💡 文件管理最佳实践

### 1. 一个文件只放一个地方
用Notion标签代替重复存放

### 2. 定期归档
每月把当月文件移动到归档文件夹

### 3. 不要过度分类
5个大类 + 3个子类 = 够用了

### 4. 用搜索代替分类
Windows搜索足够强大,不用每个文件都分类完美

### 5. 云同步重要文件
重要文件同步到OneDrive/百度网盘

## ⚠️ 常见问题

### Q: 我想要更多标签怎么办?
A: 用Notion。文件放一个地方,标签放Notion

### Q: DigiKam分类不准怎么办?
A: AI只是辅助,自己手动调整即可

### Q: 照片太多整理不完?
A: 从最新的开始整理,旧的以后再说

### Q: 文件名太乱不想改?
A: 可以不改。用Notion记录路径和标签就行
