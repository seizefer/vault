# 🌐 浏览器标签页清理指南 (傻瓜式)

> 从400+标签页到50个以内,每天15分钟,2周搞定

---

## 🎯 目标

- **第1周**: 400个 → 200个 (每天清理30个)
- **第2周**: 200个 → 50个 (每天清理20个)
- **长期**: 保持在50个以内

---

## 📦 第一步：安装工具 (5分钟)

### 必装插件 (不需要配置)

#### 1. OneTab
**作用**: 一键把当前窗口所有标签页保存成列表,释放内存

**安装**:
1. 打开Edge扩展商店 (edge://extensions/)
2. 搜索 "OneTab"
3. 点击"获取"
4. 安装完成后,工具栏会出现图标

**使用方法**:
- 点击图标 → 当前窗口所有标签页变成一个列表
- 需要时点击链接恢复
- 可以导出成文本

#### 2. Notion Web Clipper
**作用**: 一键把网页保存到Notion

**安装**:
1. Edge扩展商店搜索 "Notion Web Clipper"
2. 点击"获取"
3. 安装后登录Notion账号
4. 设置默认保存到"知识库"

**使用方法**:
- 在想保存的网页上点击图标
- 选择保存位置
- 点击"Save page"

#### 3. Copy All URLs (可选)
**作用**: 批量复制所有标签页链接

**安装**:
1. 搜索 "Copy All URLs"
2. 安装

**使用方法**:
- 点击图标 → 所有标签页URL复制到剪贴板
- 可以粘贴到记事本暂存

## 🚨 第二步：紧急止血 (10分钟)

### 立即执行

**1. 用OneTab保存所有标签页**

```
操作步骤:
1. 打开Edge
2. 看到15-20个窗口?别怕
3. 切换到第一个窗口
4. 点击OneTab图标
5. 所有标签页变成列表 ✅
6. 重复2-5步,处理所有窗口
```

**2. 完成后你会看到:**
- 浏览器只剩1个窗口
- OneTab页面里有你的所有链接
- 电脑立刻变快了!

**恭喜!你已经止血了!**

现在你有了一个"待处理清单",而不是几百个占内存的标签页。

## 📋 第三步：每日清理流程 (15分钟/天)

### 清理工作流

```
打开OneTab → 从上往下看 → 每个链接做判断 → 关闭/保存/行动
```

### 每个链接的判断 (5秒决策)

问自己这3个问题:

**Q1: 过去1个月我用过这个网页吗?**
- 没有 → 直接删除 ❌
- 有 → 继续判断

**Q2: 未来1个月我会用这个网页吗?**
- 不会 → 直接删除 ❌
- 会 → 继续判断

**Q3: 这个网页的内容是什么?**
- 知识/教程/参考 → 保存到Notion知识库 📚
- 待办事项 → 添加到Notion任务库 ✅
- 想买的东西 → 保存到Notion资料库 📦
- 临时搜索结果 → 直接删除 ❌
- 需要立即处理 → 打开处理,然后关闭

### 保存到Notion的操作

**方法1: 使用Web Clipper (最快)**
1. 在OneTab里点击链接打开网页
2. 点击Notion Web Clipper图标
3. 选择"知识库"
4. 点击Save
5. 关闭标签页
6. 在OneTab里删除这条链接

**方法2: 手动添加 (更灵活)**
1. 复制网页标题
2. 复制网页链接
3. 打开Notion知识库
4. 新建条目,粘贴标题和链接
5. 选择分类和来源
6. (可选) 写一句话摘要
7. 关闭标签页

### 每日目标

| 阶段 | 每日清理数 | 方法 |
|------|------------|------|
| 第1-3天 | 50个 | 快速判断,多删少存 |
| 第4-7天 | 30个 | 正常速度 |
| 第2周 | 20个 | 精细整理 |

## 📊 不同类型标签页的处理方案

### 1. 学术论文/课程
```
判断: 这个课程我真的会学吗?
- 会学 → 保存到知识库,关联到学习项目
- 不会 → 删除!
```

### 2. CS教程/技术文章
```
判断: 我现在正在学这个技术吗?
- 正在学 → 保存到知识库,分类=技术
- 以后可能学 → 保存,标记"稍后阅读"
- 只是随便看看 → 删除!
```

### 3. 游戏攻略
```
判断: 我还在玩这个游戏吗?
- 还在玩 → 保存到知识库,分类=游戏
- 已经不玩了 → 删除!
```

### 4. 画师主页/作品
```
判断: 我会反复看这个画师吗?
- 会 → 保存到资料库,分类=画师
- 只是路过 → 删除!
```

### 5. 购物/比价页面
```
判断: 我真的要买吗?
- 要买 → 保存到资料库,加入购物清单
- 只是看看 → 删除!
```

### 6. 日常搜索结果
```
例如: 如何煮意面、附近药店地址
→ 99%直接删除!用的时候再搜
```

### 7. 待办事项相关
```
例如: 要填的表格、要回复的邮件
→ 添加到任务库,设置截止日期,然后关闭标签页
```

## 💡 提高效率的技巧

### 1. 批量处理同类标签页

如果OneTab里有一堆游戏攻略:
1. 先把所有游戏攻略链接复制出来
2. 打开Notion知识库
3. 批量创建条目(或用AI帮你总结)
4. 回到OneTab批量删除

### 2. 使用AI加速

复制一批链接给ChatGPT/Claude:
```
请帮我为以下网页生成标题和一句话摘要:
[粘贴链接]
```

然后把结果粘贴到Notion。

### 3. 设置"不保存"规则

这些类型直接删,不用思考:
- ❌ 搜索结果页
- ❌ 登录页面
- ❌ 已经过期的活动
- ❌ 3个月前打开但从未看过的
- ❌ "有空再看"但一直没看的

### 4. 时间盒子法

设定15分钟计时器:
- 计时开始 → 开始清理
- 计时结束 → 立即停止
- 不管清了多少,明天继续

这样不会整理到心累。

## ⚠️ 常见问题

### Q: 我怕关了找不到怎么办?
A:
1. 保存到Notion就不会丢
2. Notion有搜索功能
3. 大部分网页Google一下就能找回来
4. 问问自己:过去3个月你找过它吗?

### Q: 我有选择困难怎么办?
A: 设置规则:犹豫超过5秒 → 先保存到Notion再说

### Q: 清理到一半不想清了
A:
1. 用时间盒子法,15分钟就停
2. 减少目标,从50个降到20个
3. 记住:进步比完美重要

### Q: 新标签页又开始堆了
A:
1. 立即安装Web Clipper
2. 看完一个网页 → 保存或关闭
3. 不要"先放着以后看"

### Q: OneTab崩了/数据丢了
A:
1. 定期导出OneTab列表
2. 重要的先保存到Notion
3. 丢了也别心疼,大部分你不会用
