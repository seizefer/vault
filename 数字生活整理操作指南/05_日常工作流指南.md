# 🔄 日常工作流指南

> 建立可持续的信息收集→处理→回顾流程,防止数字囤积症复发

---

## 🎯 工作流的目标

1. **防止复发**: 不让标签页/收藏夹再次堆积
2. **快速收集**: 看到好内容3秒内处理完
3. **定期回顾**: 确保收集的内容真的被使用

---

## 🌊 信息流动的三个阶段

```
收集 → 处理 → 回顾
 ↓      ↓      ↓
入口    整理    使用
```

### 阶段1: 收集 (实时)
- 看到好内容 → 立即扔进系统
- 不做判断,不做分类
- 3秒完成

### 阶段2: 处理 (每日/每周)
- 清空收集箱
- 分类整理
- 删除无用的

### 阶段3: 回顾 (每周/每月)
- 检查是否真的在用
- 删除过期内容
- 优化系统

---

## 📥 统一收集入口

### 你的三个入口

| 入口 | 收集内容 | 工具 |
|------|----------|------|
| Notion | 网页、文章、想法 | Web Clipper / 手动 |
| 本地文件夹 | 文件、照片 | 文件管理器 |
| flomo | 即时灵感 | App |

**规则**: 其他地方(微信、QQ、便签)只是临时中转,必须当天转移到以上三个入口。

## 🌅 每日工作流

### 早上 (5分钟)

```
08:00 打开Notion
    ↓
查看任务库 → 确定今日3件事
    ↓
查看日历 → 有无deadline
    ↓
开始工作
```

### 白天 (实时收集)

**场景1: 浏览网页时看到好文章**
```
方法A: Notion Web Clipper
1. 点击扩展图标
2. 选择"知识库"
3. 点Save
4. 关闭标签页 ✅

方法B: 手动添加
1. 复制标题+链接
2. 粘贴到Notion
3. 关闭标签页 ✅
```

**场景2: 突然有个想法**
```
1. 打开flomo(或Notion灵感箱)
2. 快速记下
3. 不用整理,晚上处理
```

**场景3: 需要做的事情**
```
1. 打开Notion任务库
2. 添加任务
3. 设优先级
4. 继续工作
```

**场景4: 收到重要文件**
```
1. 保存到本地对应文件夹
2. 命名: 2025-01_主题_内容
3. (可选) 在Notion记录路径
```

### 晚上 (15分钟)

```
21:00 整理时间
    ↓
清理今日新开的标签页 (5分钟)
    - 有用 → Notion
    - 没用 → 关闭
    ↓
处理flomo/灵感箱 (5分钟)
    - 有价值 → 转知识库/任务
    - 随手记 → 保留
    - 垃圾 → 删除
    ↓
写日记 (5分钟)
    - 今日完成了什么
    - 整理了多少内容
    - 明天要做什么
```

## 📅 每周工作流

### 周日晚上 (30分钟)

#### 1. 回顾本周 (10分钟)
```
打开Notion日记
    ↓
看这周7天的记录
    ↓
统计:
- 清理标签页: __个
- 整理照片: __张
- 完成任务: __个
```

#### 2. 清理收集箱 (10分钟)
```
检查以下地方是否清空:
- [ ] flomo待处理
- [ ] 浏览器"稍后阅读"
- [ ] B站"待看"收藏夹
- [ ] 下载文件夹
```

#### 3. 规划下周 (10分钟)
```
打开Notion任务库
    ↓
查看未完成任务
    ↓
设定下周Top 3任务
    ↓
写到日记里
```

## 📆 每月工作流

### 每月最后一天 (1小时)

#### 1. 月度回顾 (20分钟)
```
统计本月:
- 知识库新增: __条
- 完成任务: __个
- 删除内容: __个

反思:
- 什么做得好?
- 什么需要改进?
- 下月重点是什么?
```

#### 2. 深度清理 (30分钟)
```
清理这些地方:
- [ ] Notion知识库 - 删除过期内容
- [ ] 下载文件夹 - 归档或删除
- [ ] 照片 - 删除本月拍的垃圾照片
- [ ] 收藏夹 - 删除没看的内容
```

#### 3. 系统优化 (10分钟)
```
问自己:
- 收集流程顺畅吗?
- 哪个环节经常卡住?
- 需要调整分类吗?
```

## 🔧 具体场景工作流

### 场景1: 看B站视频时发现好教程

**以前的做法** (错误):
```
点收藏 → 堆积 → 找不到 → 忘记
```

**现在的做法** (正确):
```
方式A: 立即处理
1. 复制视频标题和链接
2. 打开Notion知识库
3. 新建条目,粘贴
4. 来源=B站,分类=技术
5. 关联到学习项目(可选)

方式B: 稍后处理
1. 收藏到"待看"收藏夹
2. 晚上整理时处理
3. 有价值→Notion,没价值→删除
```

### 场景2: 知乎看到好回答

```
1. 点击分享 → 复制链接
2. Notion知识库新建条目
3. 来源=知乎
4. 写一句话摘要(为什么值得保存)
5. 不要只收藏不总结!
```

### 场景3: 微信群有人分享好资料

```
1. 立即下载文件
2. 保存到本地对应文件夹
3. 在Notion记录(可选)
4. 不要"先存着以后看"
```

### 场景4: 逛淘宝看到想买的东西

```
1. 打开Notion资料库
2. 添加到购物清单
3. 写下:为什么想买?预算多少?
4. 不要打开一堆商品标签页!
```

### 场景5: 睡前突然想到一个idea

```
1. 打开flomo/灵感箱
2. 快速记下
3. 不要展开写,明天处理
4. 睡觉
```

## ⚡ 快速决策框架

### 3秒决策法

看到任何信息,问自己:

```
这个信息,3个月后我会用到吗?
    ├── 会 → 保存
    └── 不会/不确定 → 不保存
```

### 2分钟规则

如果一件事2分钟能做完:
- 立即做
- 不要加到To-Do

### PARA原则简化版

所有内容只分4类:
- **P**rojects (进行中的项目)
- **A**reas (长期关注的领域)
- **R**esources (参考资料)
- **A**rchive (存档)

## 🚫 避免复发的规则

### 规则1: 一进一出
```
每收藏1个新内容 → 必须删除1个旧内容
```

### 规则2: 定期归零
```
每周必须清空:
- flomo待处理
- 浏览器标签页 < 30
- 下载文件夹
```

### 规则3: 不囤积"以后看"
```
如果标记"稍后阅读":
- 必须写下:什么时候看?
- 超过2周没看 → 删除
```

### 规则4: 收集≠学习
```
收藏了不代表学会了
只有加工过的才是你的知识
- 摘录关键句
- 写自己的理解
- 关联到已有知识
```

## 📱 工具协作流程

### Notion (主力)
- 所有知识和任务的最终归宿
- 每天打开
- 搜索入口

### flomo (辅助)
- 即时灵感记录
- 不适合在Notion里快速输入时用
- 每天清空到Notion

### 本地文件夹 (底座)
- 所有文件的物理存储
- 不重复存放
- Notion记录路径和标签

### 浏览器
- 只是浏览工具
- 用完即关
- 不用来保存信息

## ⚠️ 常见问题

### Q: 流程太复杂记不住?
A: 先只做"收集→晚上整理→写日记",其他以后加

### Q: 没时间每天整理?
A: 减少到5分钟,重要的是每天都做

### Q: 总是忘记整理?
A: 设闹钟,绑定已有习惯(如刷牙后)

### Q: 整理着整理着又开始囤积?
A: 正常,重新开始每日清理,不要自责
