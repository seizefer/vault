# 🛠️ 工具推荐清单 (无需代码)

> 所有推荐的工具都是:免费/便宜 + 不需要技术 + 几分钟上手

---

## 🎯 工具选择原则

1. **能不装就不装** - 系统自带能解决就用自带的
2. **简单优先** - 功能够用就行,不追求强大
3. **本地优先** - 尽量选择不上传数据的
4. **免费优先** - 除非付费版明显更好

---

## 📌 必装工具 (Day 1)

### 1. OneTab
**用途**: 一键保存所有标签页,释放内存

| 项目 | 内容 |
|------|------|
| 价格 | 免费 |
| 安装 | Edge/Chrome扩展商店 |
| 难度 | ⭐ (点一下就会) |
| 必要性 | ⭐⭐⭐⭐⭐ |

**安装步骤**:
1. 打开Edge扩展商店
2. 搜索"OneTab"
3. 点击"获取"
4. 完成

**使用方法**:
- 点击图标 → 所有标签页变成列表
- 点击链接 → 恢复标签页
- 点击"导出" → 导出成文本

---

### 2. Notion Web Clipper
**用途**: 一键保存网页到Notion

| 项目 | 内容 |
|------|------|
| 价格 | 免费 |
| 安装 | Edge/Chrome扩展商店 |
| 难度 | ⭐ |
| 必要性 | ⭐⭐⭐⭐⭐ |

**安装步骤**:
1. 扩展商店搜索"Notion Web Clipper"
2. 安装
3. 点击图标,登录Notion账号
4. 设置默认保存位置为"知识库"

**使用方法**:
- 在网页上点击图标
- 选择保存位置
- 点击"Save page"
- 自动保存标题、链接、内容

## ⚠️ 工具使用注意

### 不要陷入工具陷阱
- 工具是手段,不是目的
- 不要花大量时间研究工具
- 够用就行

### 保持简单
- 不是功能越多越好
- 能用自带的就用自带的
- 工具少一点,专注多一点

### 建立统一流程
- 所有工具服务于同一个流程
- Notion是最终归宿
- 其他工具只是辅助
