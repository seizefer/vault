# Notion 模板集合

本文档包含所有Notion数据库和页面的模板，可以直接复制使用。

## 📥 1. INBOX 数据库模板

### 数据库属性

```
Name: 标题 (Title)
Type: 类型 (Select)
  - 链接
  - 想法
  - 待办
  - 文章
  - 视频
  - 图片
  - 其他

Source: 来源 (Select)
  - Edge
  - Chrome
  - B站
  - 小红书
  - 知乎
  - Twitter
  - 微博
  - 脑海
  - 手机
  - 其他

Date Added: 添加日期 (Created time)
Status: 状态 (Select)
  - 📥 未处理
  - 🔄 处理中
  - ✅ 已转移
  - 🗑️ 删除

Content: 内容/备注 (Text)
```


## 💡 使用建议

1. **不要全部使用**
   - 根据需要选择模板
   - 新手建议从简化版开始

2. **逐步完善**
   - 先用基础模板
   - 慢慢添加自己需要的字段

3. **定期优化**
   - 删除不用的字段
   - 添加常用的字段

4. **保持简洁**
   - 模板越简单越容易坚持
   - 不要为了完美而放弃使用
