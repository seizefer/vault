# 移动端工作流指南

在手机上如何高效使用个人信息系统

---

## 📱 为什么需要移动端工作流？

**现实场景：**
- 通勤路上看到有价值的文章
- 突然冒出一个想法
- 临时需要查看今日待办
- 躺在床上想记录今天的事

**问题：**
- Notion移动端体验不如电脑
- 输入慢、操作复杂
- 容易打开就忘记要做什么

**解决方案：**
- 移动端只做3件事：**记录、查看、快速处理**
- 深度处理留给电脑

---

## 🎯 移动端核心原则

```
1. 快速记录 > 完美分类
2. 使用语音输入
3. 简化版模板
4. 定期同步到电脑端
```

## 📲 移动端Notion设置

### 1. 下载安装

```
iOS: App Store搜索"Notion"
Android: Google Play / 应用商店搜索"Notion"
```

### 2. 首次设置

```
1. 登录账号（与电脑端同步）
2. 固定常用页面：
   ☐ INBOX
   ☐ DAILY
   ☐ Tasks (Today视图)
3. 开启通知（可选）
4. 设置默认新页面位置 → INBOX
```

### 3. 创建移动端专用页面

在Notion中创建：
```
📱 Mobile Quick Capture (移动端快速捕获)
```

## ⚡ 3大核心场景

### 场景1: 快速记录想法/链接

**步骤（10秒完成）：**

```
1. 打开Notion App
2. 点击右下角"+"
3. 选择"INBOX"作为位置
4. 使用语音输入：
   "在XXX看到XXX，关于XXX"
5. 点击保存 → 完成
```

**简化模板（移动端Inbox）：**
```markdown
[内容]

来源: [哪里]
原因: [为什么保存]
```

**更快的方法 - 使用iOS Shortcuts/Android快捷方式：**

创建快捷指令：
```
名称: "快速记到Notion"
步骤:
  1. 获取剪贴板内容
  2. 要求输入"为什么保存？"
  3. 添加到Notion INBOX
```

---

### 场景2: 查看今日待办

**步骤（5秒）：**

```
1. 打开Notion
2. 点击"Favorites"中的"今日待办"
   （提前在电脑端创建并固定）
3. 查看今天要做的3-5个任务
```

**移动端Today视图设置：**

在电脑端创建Tasks的视图：
```
视图名称: 📱 Today
筛选条件:
  - Due Date = Today
  - Status ≠ 完成
排序:
  - Priority (降序)
显示:
  - 只显示 Task Name, Priority, Status
```

---

### 场景3: 晚上记录Daily

**步骤（3分钟）：**

```
1. 打开Notion → DAILY
2. 找到今天的页面
3. 使用极简模板填写（见下）
```

**移动端Daily极简模板：**

```markdown
# [日期]

## 今天做了
-

## 今天学到
-

## 今天想法
-

## 明天要做
- [ ]
- [ ]
```

**语音输入技巧：**
- 开启手机语音输入
- 说完一段点"完成"再说下一段
- 不要边说边看屏幕（容易分心）

## 🔄 移动端日常工作流

### 🌅 早晨 (5分钟)

```
场景: 通勤路上

☐ 打开Notion "今日待办"视图
☐ 浏览今天要做的事
☐ 在心里规划优先级
☐ （可选）在某个任务下添加备注

不要：
❌ 不要在手机上创建新任务（太慢）
❌ 不要修改任务属性（留给电脑）
❌ 不要深入阅读资料（专注力分散）
```

### 📱 白天 (随时，每次<1分钟)

```
场景: 任何时候有想法/看到好内容

☐ 立即打开Notion
☐ 点击"+"
☐ 语音输入或粘贴链接
☐ 添加一句话说明
☐ 保存到INBOX → 完成

不要：
❌ 不要试图立即分类（晚上电脑端处理）
❌ 不要写太长（简单记录即可）
❌ 不要打开看很久（先记录，回头再看）
```

### 🌙 晚上 (5分钟)

```
场景: 睡前躺在床上

☐ 打开Notion DAILY
☐ 使用极简模板记录今天
☐ 不追求完美，写几句话即可
☐ （可选）查看明天待办

不要：
❌ 不要处理Inbox（留给电脑）
❌ 不要详细复盘（简单记录即可）
❌ 不要规划太多（明天早上电脑端做）
```

```yaml

输入: 无

     "

```

#### 2. "今日总结"快捷指令

```yaml
名称: 今日总结

  2. 询问: "今天学到什么？"

  5. 创建Daily页面
  6. 显示通知: "Daily已创建"
```

```yaml
名称: 今日待办
输入: 无
步骤:
  1. 打开Notion URL: notion://www.notion.so/[your-today-view-id]
```

**设置方法：**
1. 打开iOS "快捷指令" App
2. 点击 "+" 创建新快捷指令
3. 搜索并添加对应的操作
4. 添加到主屏幕

## 🔗 与其他App的集成

### 1. 浏览器 → Notion

**方案A: 使用"分享"功能**
```
1. 在浏览器看到好文章
2. 点击"分享"
3. 选择"Notion"
4. 选择目标: INBOX
5. （可选）添加备注
6. 保存
```

**方案B: 使用书签栏**
```
1. 收藏到浏览器书签
2. 晚上在电脑端统一处理
3. 用工具（bookmark_analyzer.py）批量导入Notion
```

### 2. 微信/QQ → Notion

**方案A: 复制粘贴**
```
1. 长按消息 → 复制
2. 打开Notion → INBOX
3. 粘贴
4. 添加备注
```

**方案B: 转发到文件传输助手 → 电脑处理**
```
1. 转发到"文件传输助手"
2. 晚上在电脑端统一处理
```

### 3. 小红书/B站/知乎 → Notion

**不推荐在移动端处理**

理由：
- App内不方便复制链接
- 容易陷入继续浏览的陷阱

**推荐方法：**
```
1. 使用App内的"收藏"功能
2. 周末在电脑端批量处理
3. 使用脚本导出（见工具文档）
```

## ⚡ 移动端效率技巧

### 1. 语音输入

**iOS语音输入：**
```
- 点击键盘上的麦克风图标
- 说话（支持中英混输）
- 点击"完成"
- 自动转为文字
```

**Android语音输入：**
```
- 使用Gboard或搜狗输入法
- 点击麦克风
- 说话并自动识别
```

**技巧：**
- 不要边说边看屏幕（准确率更高）
- 说完整的句子（不要断断续续）
- 标点符号可以说出来："逗号"、"句号"

### 2. 模板快速访问

在Notion创建：
```
📱 Mobile Templates (移动端模板)
├─ 快速Inbox条目
├─ 极简Daily
├─ 快速任务
└─ 灵感记录
```

使用：
1. 打开模板页面
2. 复制模板
3. 粘贴到目标位置
4. 填写内容

### 3. 使用Notion Web Clipper

iOS/Android都可以安装Notion的"分享扩展"

**使用方法：**
```
1. 在任意App中
2. 点击"分享"按钮
3. 滑动找到"Notion"
4. 选择保存位置
5. 完成
```

## 🚫 移动端不要做的事

```
❌ 不要在手机上：
  - 深度整理Inbox（屏幕太小，效率低）
  - 批量处理文件（操作不便）
  - 创建复杂的数据库（难以操作）
  - 长时间浏览资料（伤眼睛）
  - 详细规划项目（需要大屏幕思考）

✅ 手机只用来：
  - 快速记录（<1分钟）
  - 查看待办（<5分钟）
  - 简单记录Daily（<5分钟）
  - 紧急查询信息
```

```
每日移动端使用Notion时间: <15分钟

分配:
- 早晨查看待办: 3分钟
- 白天快速记录: 5分钟（累计，每次<1分钟）
```

## 🆘 移动端常见问题

### Q1: 手机上Notion太慢怎么办？

```
A:
1. 减少页面内容（移动端专用简化版）
2. 关闭自动加载图片
3. 使用WiFi而非移动网络
4. 清理App缓存
5. 等回到电脑再处理（最推荐）
```

### Q2: 打字太慢怎么办？

```
A:
1. 使用语音输入（准确率80%+）
2. 使用快捷短语（iOS文本替换）
3. 减少输入量（只记关键词）
4. 拍照代替打字
5. 语音备忘录 → 回电脑再转文字
```

### Q3: 容易忘记打开Notion怎么办？

```
A:
1. 设置每天固定时间的闹钟/提醒
   - 早9:00: "查看今日待办"
   - 晚10:00: "记录今天"
2. 把Notion放在手机主屏幕
3. 使用Widget（iOS/Android）
4. 建立习惯触发器（如：坐地铁→打开Notion）
```

### Q4: 手机记录了但电脑端看不到？

```
A:
1. 检查网络连接
2. 手动下拉刷新
3. 关闭App重新打开
4. 检查是否登录同一账号
5. 等待几秒钟同步
```
