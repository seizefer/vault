# 🎯 个人项目 Personal Projects

> 管理你的个人目标、生活项目、技能提升计划。不是学习课程,而是你想做的事情。

---

## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 项目名称 | 标题 | 项目的名称 |
| 类型 | 选择 | 求职/健身/理财/技能/创作/整理/兴趣 |
| 进度 | 选择 | 📋未开始 / 🏃进行中 / ✅已完成 / ⏸️暂停 |
| 完成度 | 数字 | 0-100% |
| 开始日期 | 日期 | 开始时间 |
| 目标完成日期 | 日期 | 预计完成时间 |
| 项目描述 | 文本 | 这个项目是什么,要达成什么目标 |
| 下一步行动 | 文本 | 具体的下一步该做什么 |
| 相关任务 | 关联 | 关联到任务库 |
| 相关资源 | 关联 | 关联到知识库 |
| 标签 | 多选 | 长期项目、短期目标、每日习惯 |

## 🎯 使用技巧

### 项目分类建议
- **求职**: 实习、校招、跳槽准备
- **健身**: 运动、减肥、健康管理
- **理财**: 记账、投资学习
- **技能**: 摄影、写作、设计等技能提升
- **创作**: 博客、视频、作品集
- **整理**: 信息整理、断舍离
- **兴趣**: 业余爱好项目

### 项目管理原则
1. **同时进行的项目 ≤ 3个** - 太多会分散精力
2. **定期回顾暂停项目** - 每月检查一次,继续或放弃
3. **设定明确的完成标准** - 什么叫"完成"?
4. **拆分成可执行任务** - 项目→任务库→每日执行

### 不同视图
- **活跃项目**: 筛选 进度=进行中
- **按类型分组**: 分组显示 类型
- **本月目标**: 筛选 目标完成日期=本月
- **成就墙**: 筛选 进度=已完成
