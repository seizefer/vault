# 📝 日记 Daily

> 记录每日生活、整理进度、心情状态。这是你数字生活整理的"进度条"。

---

## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日期 | 日期 | 自动填充今天日期 |
| 今日记录 | 文本 | 今天的想法、发生的事 |
| 整理进度 | 文本 | 今天整理了什么 |
| 今日任务完成 | 文本 | 完成的任务列表 |
| 心情 | 选择 | 😊开心 / 😐平静 / 😔低落 / 😤焦虑 |
| 能量值 | 选择 | ⚡⚡⚡ / ⚡⚡ / ⚡ |
| 标签 | 多选 | 高效、拖延、学习、运动、社交 |

## 🎯 使用技巧

### 写日记的最佳时间
- **晚上睡前10分钟** - 回顾一天,记录整理进度
- 不需要长篇大论,3-5句话即可

### 重点记录什么
1. **整理进度** - 今天清理了多少标签页/照片/文件
2. **完成的任务** - 给自己正反馈
3. **心情变化** - 观察整理对情绪的影响
4. **遇到的问题** - 记录卡点,后续优化

### 视图建议
- **本周日记**: 过滤 日期=本周
- **高效日**: 过滤 标签包含"高效"
- **低效反思**: 过滤 标签包含"拖延"
- **心情趋势**: 按心情分组查看
