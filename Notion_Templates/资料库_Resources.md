# 📚 资料库 Resources

> 长期保存的生活资源、工具、清单。不是知识,而是"你会反复查阅的参考资料"。

---

## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 资源名称 | 标题 | 资源的名称 |
| 类型 | 选择 | 工具/清单/模板/灵感/指南/资源合集 |
| 分类 | 选择 | 游戏/影视/购物/旅行/学习/效率/设计 |
| 链接/路径 | URL/文本 | 资源的访问方式 |
| 描述 | 文本 | 这是什么,什么时候会用到 |
| 标签 | 多选 | 常用、收藏、待整理 |
| 添加日期 | 日期 | 记录时间 |
| 使用频率 | 选择 | 每天用/每周用/偶尔用/很少用 |

## 🎯 使用技巧

### 资料库 vs 知识库的区别
| 资料库 Resources | 知识库 Knowledge Base |
|----------------|----------------------|
| 工具、清单、模板 | 文章、教程、视频 |
| 会反复查阅 | 读完就不看了 |
| 偏实用 | 偏学习 |
| 例:待看电影清单 | 例:影评文章 |

### 资料类型说明
- **工具**: 在线工具、软件、网站
- **清单**: 待办清单、愿望清单、收藏清单
- **模板**: 简历模板、PPT模板、Notion模板
- **灵感**: 设计灵感、配色方案、摄影参考
- **指南**: 长期参考的攻略、手册
- **资源合集**: 导航站、资源整合网站

### 不同视图
- **常用工具**: 筛选 标签=常用
- **按分类查看**: 分组显示 分类
- **按使用频率**: 分组显示 使用频率
- **待整理**: 筛选 标签=待整理
