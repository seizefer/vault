## ✅ 导入前准备 (2分钟)

- [ ] 注册Notion账号 (如果还没有)
- [ ] 下载这个文件夹到本地
- [ ] 确认7个.md文件都在

---

## 📥 导入步骤 (5分钟)

### 方法1: 逐个导入 (适合新手)

**Step 1: 导入HOME主页**
1. 打开Notion
2. 点击左侧 "+ New page"
3. 输入 `/import`
4. 选择 "Markdown & CSV"
5. 上传 `HOME.md`
6. ✅ 主页创建完成!

**Step 2: 导入其他6个数据库**
重复以上步骤,依次导入:
- [ ] 知识库_Knowledge_Base.md
- [ ] 任务库_Task.md
- [ ] 日记_Daily.md
- [ ] 灵感收集箱_Inbox.md
- [ ] 学习项目_Study_Projects.md
- [ ] 个人项目_Personal_Projects.md
- [ ] 资料库_Resources.md

### 方法2: 批量导入 (快但可能失败)

1. 在Notion新建页面,命名"个人管理系统"
2. 输入 `/import`
3. 选择整个 `Notion_Templates` 文件夹
4. 等待导入完成
5. 检查是否所有文件都导入成功

## 🔧 导入后必做调整 (3分钟)

### 知识库字段调整

导入后,进入知识库页面:

1. 点击右上角 "..." → "Database" → 查看所有字段
2. 调整以下字段类型:

| 字段名 | 当前类型 | 改为 |
|--------|---------|------|
| 来源 | Text | Select |
| 分类 | Text | Select |
| 标签 | Text | Multi-select |
| 是否重要 | Text | Checkbox |
| 状态 | Text | Select |
| 添加日期 | Text | Date |

**如何修改:**
- 点击字段名
- 选择 "Edit property"
- 修改 "Type"

3. 添加选择项:

**来源字段选项:**
```

```

**分类字段选项:**


**状态字段选项:**
```

```

### 其他数据库同理调整

**任务库:**
- 分类 → Select (生活/工作/学习/健康/个人项目)
- 优先级 → Select (🔴高/🟡中/🟢低)
- 状态 → Select (📋未开始/🏃进行中/✅已完成)
- 截止日期 → Date

**日记:**

## ⚠️ 如果导入失败

### 方案A: 手动创建数据库
1. 在Notion新建页面
2. 输入 `/database`
3. 选择 "Database - Full page"
4. 参考模板文件,手动添加字段
5. 复制示例内容

### 方案B: 复制粘贴内容
1. 打开.md文件
2. 复制内容
3. 在Notion粘贴
4. Notion会自动识别markdown格式

### 方案C: 使用Notion模板市场
1. 搜索 "personal knowledge management"
2. 选择类似的模板
3. 根据我们的模板调整
