# ✔️ 任务库 Task

> 把Microsoft To Do、手机备忘录、OneNote中的待办事项全部迁移到这里,统一管理。

---

## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 任务描述 | 标题 | 具体要做的事情 |
| 分类 | 选择 | 生活/工作/学习/健康/个人项目 |
| 优先级 | 选择 | 🔴高 / 🟡中 / 🟢低 |
| 截止日期 | 日期 | 可选,有deadline的才填 |
| 状态 | 选择 | 📋未开始 / 🏃进行中 / ✅已完成 |
| 预计耗时 | 文本 | 15分钟 / 1小时 / 半天 等 |
| 相关项目 | 关联 | 关联到学习项目或个人项目 |
| 添加日期 | 日期 | 自动记录 |

## 🎯 使用技巧

### 任务分解原则
- 大任务要拆成小任务
- 每个小任务 < 2小时
- 例如: "整理所有标签页" → 拆成"整理游戏标签组"、"整理技术标签组"

### 优先级判断
- 🔴 **高**: 有明确deadline + 重要
- 🟡 **中**: 重要但不紧急,或紧急但不重要
- 🟢 **低**: 可做可不做,有空再做

### 不同视图建议
- **今日任务**: 筛选 截止日期=今天 或 优先级=高
- **本周任务**: 筛选 截止日期=本周
- **进行中**: 筛选 状态=进行中
- **按分类查看**: 分组显示 分类

### 与其他数据库的联动
- **灵感箱 → 任务库**: 可执行的想法转为任务
- **任务库 → 日记**: 每天记录完成的任务
- **任务库 ← 项目**: 大项目拆解出多个小任务
