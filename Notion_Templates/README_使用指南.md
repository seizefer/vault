## 🚀 快速开始 (3步搞定)

### Step 1: 导入到Notion

**方法A: 逐个导入 (推荐新手)**
1. 打开Notion,创建一个新页面
2. 在Notion中输入 `/import`
3. 选择 "Markdown & CSV"
4. 上传这个文件夹中的 `.md` 文件
5. 重复以上步骤,导入所有7个文件

**方法B: 批量导入**
1. 在Notion中创建一个新的父页面,命名为"个人管理系统"
2. 使用 `/import` 选择整个文件夹
3. Notion会自动识别所有markdown文件并创建对应页面

**方法C: 手动创建 (如果导入失败)**
1. 在Notion中手动创建数据库
2. 参考模板文件中的字段定义,逐个添加字段
3. 复制示例条目的内容,粘贴到Notion

### Step 2: 调整数据库字段

导入后,Notion可能无法完全识别字段类型,需要手动调整:

**知识库必须设置的字段:**
- 来源 → 选择类型 (添加选项: Edge, Chrome, B站, 知乎, Twitter等)
- 分类 → 选择类型 (添加选项: 学术, 技术, 游戏, 影视等)
- 标签 → 多选类型
- 是否重要 → 复选框类型
- 状态 → 选择类型 (选项: 未读, 已读, 稍后阅读)

**其他数据库同理调整**

### Step 3: 开始使用!

1. **第一天**: 清理20个浏览器标签页 → 丢进知识库
2. **第二天**: 把flomo/便签内容复制到灵感箱
3. **第三天**: 整理50张手机照片
4. **第四天**: 把to-do迁移到任务库
5. **第五天**: 开始写第一篇日记

## 💡 使用技巧

### 整理浏览器标签页的最快方法
1. 打开一个标签页
2. 复制标题 (Ctrl+C)
3. 在Notion知识库新建条目,粘贴标题
4. 复制链接,粘贴到"链接"字段
5. 选择"来源"和"分类" (2秒)
6. 关闭标签页
7. 下一个!

**平均每个网页 < 10秒**

### AI辅助加速 (可选)
如果你在用ChatGPT/Claude:
1. 复制一批标签页链接
2. 让AI批量生成"标题 + 一句话摘要"
3. 直接粘贴到Notion

### 定期维护建议
- **每天**: 清理15分钟标签页
- **每周**: 回顾日记,更新项目进度
- **每月**: 清理已完成任务,归档旧笔记

## ⚠️ 常见问题

### Q1: 导入后中文乱码?
A: Notion对中文markdown支持良好,如果乱码:
- 确保文件编码是 UTF-8
- 尝试使用Notion的 "Text & Markdown" 导入
- 实在不行就手动复制粘贴内容

### Q2: 导入后字段类型不对?
A: 正常现象!Notion无法完全识别字段类型,需要手动调整:
- 点击字段名 → "Edit property"
- 修改字段类型 (Text → Select / Multi-select / Checkbox 等)

### Q3: 我需要全部7个数据库吗?
A: 不需要!最核心的是这3个:
1. **知识库** - 清理标签页必须
2. **任务库** - 管理to-do必须
3. **日记** - 记录进度,保持动力

其他4个可以后续按需添加。

### Q4: 我可以修改字段吗?
A: 当然可以!这只是模板,你可以:
- 删除不需要的字段
- 添加自己需要的字段
- 修改字段名称
- 调整分类选项

### Q5: 示例条目要删掉吗?
A: 建议先保留,熟悉系统后再删。示例条目可以帮你理解每个字段怎么用。
