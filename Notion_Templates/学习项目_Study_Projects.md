## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 项目名称 | 标题 | 学习项目的名称 |
| 领域 | 选择 | CS基础/编程语言/前端/后端/AI/学术 |
| 进度 | 选择 | 📋未开始 / 🏃进行中 / ✅已完成 / ⏸️暂停 |
| 完成度 | 数字 | 0-100% |
| 开始日期 | 日期 | 开始学习的日期 |
| 目标完成日期 | 日期 | 预计完成时间 |
| 学习资源 | 关联 | 关联到知识库的相关文章/视频 |
| 学习笔记 | 文本/页面 | 记录学习笔记 |
| 相关文件 | 文件 | 本地文件的路径或附件 |
| 标签 | 多选 | 视频课程、在线课程、书籍、实战项目 |

## 🎯 使用技巧

### 项目规划建议
1. **明确学习目标**: 为什么学这个?学到什么程度?
2. **收集学习资源**: 课程、书籍、文章都关联到知识库
3. **制定学习计划**: 拆分章节,设定每周目标
4. **定期复盘**: 每周更新进度,调整计划

### 进度管理
- 每学完一个章节,更新完成度
- 如果暂停超过2周,标记为⏸️暂停
- 定期回顾暂停的项目,决定继续或放弃

### 不同视图
- **进行中的项目**: 筛选 进度=进行中
- **按领域分组**: 分组显示 领域
- **按优先级排序**: 根据目标日期排序
- **已完成项目**: 筛选 进度=已完成 (成就展示)
