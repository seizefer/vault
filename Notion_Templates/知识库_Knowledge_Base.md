# 🧠 知识库 Knowledge Base

> 这是你所有网页、文章、视频、收藏的最终归宿。浏览器标签页、B站收藏、知乎收藏、Twitter书签都放这里。

---

## 📋 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 标题 | 标题 | 文章/视频/网页的标题 |
| 链接 | URL | 原始链接地址 |
| 来源 | 选择 | Edge/Chrome/B站/知乎/Twitter/小红书 等 |
| 分类 | 选择 | 学术/技术/游戏/影视/求职/兴趣/生活/工具 |
| 标签 | 多选 | AI、Python、摄影、教程、心理、效率 等 |
| 摘要 | 文本 | 一句话总结这个内容 |
| 是否重要 | 复选框 | 标记重要内容 |
| 状态 | 选择 | 未读/已读/稍后阅读 |
| 添加日期 | 日期 | 自动记录添加时间 |

## 🎯 使用技巧

### 快速添加流程
1. 复制网页标题和链接
2. 粘贴到知识库新条目
3. 用AI写一句话摘要 (可选)
4. 选择来源和分类
5. 关闭标签页 ✅

### 不同视图建议
- **技术视图**: 过滤 分类=技术
- **B站视频视图**: 过滤 来源=B站
- **重要内容**: 过滤 是否重要=是
- **未读列表**: 过滤 状态=未读
- **本周新增**: 过滤 添加日期=本周

### 批量整理技巧
- 同一主题的标签页可以先放在临时页面
- 一次性复制所有链接
- 让AI批量总结
- 再统一录入知识库
